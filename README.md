# ربات مدیریت مود روبیکا — نسخهٔ کامل (پنل، پخش همگانی، دریافت با شماره)

## ⚠️ این نسخهٔ نهاییه — کل ریپو رو با این جایگزین کنید

## چیزی که عوض شده نسبت به نسخهٔ قبل
1. **کانال مقصد دیگه خودِ فایل رو پست نمی‌کنه.** فقط عکس+توضیحات+یک شماره
   پست می‌شه. کاربرها با فرستادن `#شماره` یا `/شماره` به پیوی ربات، فایل
   رو مستقیم دریافت می‌کنن.
2. **پنل مدیریت:** به پیوی ربات کلمهٔ رمز پنل (پیش‌فرض: `پنل`، در
   `config.json` قابل‌تغییره) رو بفرستید؛ لیست کانال‌ها با شماره میاد.
   با فرستادن شمارهٔ یک کانال، جزئیاتش (تعداد پست، تاریخ فعال‌سازی،
   وضعیت فعال/غیرفعال) رو می‌بینید.
3. **فعال/غیرفعال کردن هر کانال:** توی `config.json`، هر کانال یک فیلد
   `"enabled": true/false` داره — برای غیرفعال‌کردن موقت یک کانال، کافیه
   `false` کنید و Commit کنید.
4. **پخش همگانی:** یک رمز مخصوص خودتون رو در `config.json` (فیلد
   `broadcast_secret`) بذارید. هر وقت همون رمز رو به پیوی ربات بفرستید،
   می‌گه «پیامتو بفرست»؛ پیام بعدیتون برای همهٔ کسایی که تابه‌حال به ربات
   پیام داده‌ن (به‌جز کانال‌ها) فرستاده می‌شه.
5. **شمارش کاربران:** هر گزارش وضعیت (چه در پیام دوره‌ای، چه با فرستادن
   هر متنی به پیوی) تعداد کاربرهای یکتا رو نشون می‌ده.
6. **زمان‌بندی جدید:** هر ساعت (۱۱ تا ۲۳) یک مود پست می‌شه؛ هر ۴ ساعت
   (قابل‌تغییر با `video_every_n_hours`) **علاوه بر** مود همون ساعت، یک
   ویدیو هم پست می‌شه (نه به‌جاش).
7. **رفع باگ اصلی نسخهٔ قبل:** تشخیص فایل دیگه به نوع دقیقش (Image/Video/...)
   حساس نیست — هر فایلی که عکس یا ویدیو نباشه، به‌عنوان «فایل قابل‌دریافت»
   شناخته می‌شه؛ همین باعث می‌شد فایل‌های .mcaddon قبلاً گم بشن.

## فرمت پست‌گذاری در کانال منبع

**پیام ۱ (عکس):**
```
اسم مود
#1 #هشتگ‌دلخواه
توضیحات: توضیح دلخواه، هر چقدر خواستید
ورژن: 1.2.3
```
عدد `#1` همون شماره‌ایه که بعداً کاربرها برای گرفتن فایل می‌فرستن —
برای هر مود جدید، یک عدد جدید و یکتا بذارید (۱، ۲، ۳...).

**پیام ۲ (بلافاصله بعدش، خودِ فایل مود):**
کپشنش مهم نیست، ولی خودِ فایل باید حتماً همون شماره (`#1`) رو هم تو
کپشنش داشته باشه (می‌تونید عین پیام قبلی کپی‌پیست کنید یا فقط بنویسید
`#1`).

**ویدیو:** فقط یک پیام؛ خط اول کپشنش می‌شه عنوانش.

## راه‌اندازی
1. `config.json` رو با اطلاعات خودتون پر کنید:
   - `owner_guid`: GUID خودتون (با `/myid` در پیوی ربات بگیرید)
   - `source_channel_guid`: از قبل پر شده (`c0ECrHf06f41d4ee8759a5c9cb703079`)
   - `broadcast_secret`: یک رمز دلخواه و شخصی بذارید (چیزی که کسی حدس نزنه)
   - هر کانال مقصد: `guid` (با `/myid` داخل خود کانال بگیرید)، `name`,
     `channel_link`, `mod_photo_extra_text`, `video_extra_text`
2. بقیهٔ مراحل (Secret گیت‌هاب، cron-job.org) از قبل انجام شده و نیازی
   به تکرار نیست.
3. یک پست تستی با فرمت بالا بذارید، صبر کنید تا زنگ بعدی بخوره (یا
   دستی Run workflow بزنید)، بعد `#1` رو به پیوی ربات بفرستید تا فایل
   رو پس بگیرید — اگه گرفتید، همه‌چیز درسته.

## عیب‌یابی
تب Actions → آخرین اجرا → «Run bot» → دنبال خط‌های `DEBUG:` بگردید،
مخصوصاً `DEBUG: پیام کانال منبع -> file_type=...` که دقیقاً نشون می‌ده
فایل شما چه نوعی تشخیص داده شده.
