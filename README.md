# ربات خودکار انتشار مود و ویدیو در روبیکا (بر پایهٔ API رسمی روبیکا)

## ⚠️ این نسخهٔ نهاییه — همه‌چیز رو با این جایگزین کنید
این نسخه دیگه از هیچ کتابخونهٔ واسط غیررسمی (مثل rubka) استفاده نمی‌کنه؛
مستقیم و فقط با متدهای **مستندشدهٔ رسمی** خودِ روبیکا
(`https://botapi.rubika.ir/v3/{token}/...`) از طریق کتابخونهٔ استاندارد
`requests` کار می‌کنه. این یعنی صفر حدس دربارهٔ رفتار API.

اگه نسخهٔ قبلی (هر چی، از جمله فایل‌هایی مثل `rubika_bot.db` یا
`get_my_guid.py`) رو دارید، **همه‌شون رو پاک کنید** و فقط همین فایل‌ها
رو جایگزین کنید.

## معماری
هر ۱۵ دقیقه، GitHub Actions اسکریپت `run_bot.py` را اجرا می‌کند:
1. `getUpdates` می‌زند و پیام‌های جدید (کانال منبع + پیوی شما) را می‌گیرد.
2. مودها/ویدیوهای جدید را در `state.json` ذخیره می‌کند.
3. به `/myid` در هر چتی جواب می‌دهد (GUID همان چت را برمی‌گرداند).
4. به هر پیام دیگری در پیوی، وضعیت کلی یا (با `/bugs`) گزارش خطاها را می‌دهد.
5. سر ساعت‌های برنامه‌ریزی‌شده (۱۱ تا ۲۳، هر ۴ ساعت یک ویدیو) برای هر
   کانال مقصد پست می‌گذارد و خلاصه‌اش را به پیوی شما می‌فرستد.
6. خطاها ثبت می‌شوند، اما حداکثر هر ۱۰ دقیقه یک خلاصه به پیوی می‌رود
   (نه یکی‌یکی).

فقط ۲ فایل پایتون داریم: `bot_core.py` (توابع مشترک + ارتباط با API) و
`run_bot.py` (نقطهٔ ورود اصلی). هیچ کامپیوتر/گوشیِ روشن لازم نیست.

## مراحل راه‌اندازی از صفر
1. محتوای فعلی ریپو رو کامل پاک کنید.
2. فایل‌های این پروژه رو آپلود کنید: `config.json`, `state.json`,
   `bot_core.py`, `run_bot.py`, `requirements.txt`,
   `.github/workflows/rubika-bot.yml`.
3. `Settings → Secrets and variables → Actions → New repository secret`
   Name: `RUBIKA_BOT_TOKEN` — Value: توکن ربات.
4. به پیوی `@TLP_AdminBot` پیام بدید، بعد بنویسید **`/myid`** — GUID
   خودتون رو کپی کنید → در `config.json` بذارید توی `owner_guid`.
5. همین کار رو داخل کانال منبع و کانال مقصد هم بکنید (ربات باید ادمین هر
   دو باشه):
   - GUID کانال منبع → `source_channel_guid`
   - GUID کانال مقصد → `destination_channels` → `guid`
6. تب Actions رو فعال کنید، دستی **Run workflow** بزنید. باید پیام
   «🟢 ... راه‌اندازی شد و وصل است» رو در پیوی ببینید.
7. از این به بعد خودکار هر ۱۵ دقیقه اجرا می‌شه.

## عیب‌یابی
اگه چیزی کار نکرد: تب Actions → آخرین اجرا → مرحلهٔ «Run bot (collect +
post + owner DM)» رو باز کنید و دنبال خطوطی با پیشوند `DEBUG:` بگردید —
علت دقیق (مثلاً چه چیزی از API برگشته) همون‌جا چاپ می‌شه.

## نکاتی که ممکنه نیاز به تنظیم داشته باشن
- **فرمت کپشن کانال منبع**: تابع `parse_caption` در `bot_core.py` فرض
  می‌کنه کپشن شامل `توضیحات: ...` و `ورژن: ...` و چند هشتگ باشه، و فایل
  مود بلافاصله بعد از عکس در پیام بعدی بیاد. اگه فرمت واقعی فرق داره،
  فقط همین تابع نیاز به تنظیم regex داره.
- **ساختار دقیق فیلدهای هر پیام** (`new_message`, `file`, و...) بر اساس
  رفتار معمول این نوع APIها فرض شده؛ اگه در لاگ با خطایی مثل
  `KeyError` یا مود/ویدیوی جمع‌آوری‌نشده مواجه شدید، بگید تا با دیدن
  لاگ دقیقش (که چاپ می‌کنیم) اصلاح کنم.

## ساختار فایل‌ها
```
rubika-mod-bot/
├── config.json                       تنظیمات کانال‌ها، owner_guid، زمان‌بندی
├── state.json                        دیتابیس ساده (مود/ویدیو/تاریخچه/باگ‌ها)
├── bot_core.py                       ارتباط با API رسمی + پارس + ارسال + گزارش
├── run_bot.py                        نقطهٔ ورود اصلی (هر ۱۵ دقیقه اجرا می‌شه)
├── requirements.txt                  فقط requests
└── .github/workflows/rubika-bot.yml  زمان‌بند رایگان گیت‌هاب
```
