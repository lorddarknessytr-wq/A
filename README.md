# تغییرات

## باگ ریشه‌ای «گاهی مود/تصویر رو نمی‌ذاره» — پیدا و رفع شد
علتش این بود: توی `run_posting_schedule` و `run_force_post_typed`، مود
انتخاب‌شده **قبل از** فراخوانی `send_mod` به‌عنوان «مصرف‌شده» ثبت
می‌شد، نه بعدش. یعنی اگه ارسال شکست می‌خورد (حتی بعد از همهٔ تلاش‌های
مجدد)، همون مود برای همیشه سوخته می‌شد و دیگه هیچ‌وقت دوباره امتحان
نمی‌شد — دفعهٔ بعد یک مود کاملاً متفاوت انتخاب می‌شد که ممکن بود بازم
شکست بخوره. الان فقط **بعد از ارسال واقعاً موفق** ثبت می‌شه.

علاوه بر این:
- دانلود/آپلود مجدد فایل (`reupload_file`) قبلاً هیچ retry ای نداشت؛
  حالا مثل بقیهٔ تماس‌ها تا ۳ بار با فاصله دوباره امتحان می‌شه.
- کل زنجیرهٔ ارسال (مستقیم → forward → re-upload) اگه یک‌بار کامل شکست
  خورد، ۵ ثانیه بعد یک بار دیگه هم کامل تکرار می‌شه.

## نقل‌قول (/Quote) — افست‌ها اصلاح شد
افست بولد/نقل‌قول قبلاً بر اساس تعداد کاراکتر پایتونی حساب می‌شد. اگه
روبیکا (مثل تلگرام) از UTF-16 استفاده کنه، هر ایموجی قبل از بخش
فرمت‌شده باعث می‌شد مرز نقل‌قول جابه‌جا بشه و بخشی از متن از باکس
«بیرون بزنه» — دقیقاً همون مشکلی که گزارش شد. الان افست‌ها با واحد
UTF-16 حساب می‌شن.

## `/clearbugs`
لیست باگ‌های ثبت‌شده رو پاک می‌کنه.

## پاک‌سازی تضمینیِ یادداشت‌های قدیمی
`sent_log` (یادداشت پیام‌های دوره‌ای مثل heartbeat) قبلاً فقط وقتی یک
کلید خاص چک می‌شد پاک‌سازی می‌شد. الان در انتهای **هر** اجرا، بدون قید
و شرط، رکوردهای قدیمی‌تر از ۱ ساعت پاک می‌شن.

## ویدیوی بدون متن
دیگه پیش‌فرض «ویدیو جدید» یا خط خالی اضافه نمی‌ذاره؛ اگه عنوان خالی
باشه، اون بخش کلاً حذف می‌شه.
