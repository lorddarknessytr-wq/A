# ربات انتشار مود و ویدیو روبیکا + GitHub Actions

این نسخه مستقیماً از **Rubika Bot API v3** استفاده می‌کند و به کتابخانه `rubka` وابسته نیست. بنابراین متدهای اصلی پروژه با نام‌های مستندات رسمی (`getMe`, `getUpdates`, `sendMessage`, `sendFile`) هماهنگ شده‌اند.

## مهم: چرا نسخه قبلی ممکن بود وصل شود ولی کاری نکند؟

در پروژه قبلی، کد به `rubka` وابسته بود و هم‌زمان فرض می‌کرد پاسخ `get_updates()` دقیقاً ساختار خاصی دارد. همچنین `send_image` و `send_document` متدهای کتابخانه بودند، نه نام متدهای مستقیم API رسمی.

در این نسخه:
- احراز هویت با `getMe` انجام می‌شود.
- دریافت آپدیت با `getUpdates` انجام می‌شود.
- ارسال پیام با `sendMessage` انجام می‌شود.
- ارسال عکس/فایل/ویدیوِ دارای `file_id` با `sendFile` انجام می‌شود.
- `next_offset_id` از پاسخ `getUpdates` ذخیره می‌شود.
- اجرای دستی GitHub Actions یک پیام به پیوی مالک می‌فرستد:
  **«🟢 من هنوز زنده‌ام.»**

## تنظیمات لازم

### 1) Secret گیت‌هاب
در:
`Settings → Secrets and variables → Actions`

یک Repository Secret بساز:

- Name: `RUBIKA_BOT_TOKEN`
- Value: توکن واقعی ربات

توکن را داخل `config.json` نگذار.

### 2) GUIDها
در `config.json` این موارد را با مقدار واقعی خودت عوض کن:

- `owner_guid`
- `source_channel_guid`
- `destination_channels[].guid`

اگر فقط یک کانال مقصد داری، می‌توانی مورد دوم را حذف کنی.

### 3) لینک کانال‌ها
`channel_link` فقط متن کپشن است و برای کار API ضروری نیست؛ اگر لازم نیست، می‌توانی آن را تغییر بدهی.

## پیدا کردن GUID

1. ربات را در کانال منبع و کانال‌های مقصد ادمین کن.
2. به پیوی ربات یک پیام تست بفرست.
3. اگر لازم است کانال منبع دیده شود، یک پست جدید در آن بگذار.
4. در GitHub:
   `Actions → Find GUIDs → Run workflow`
5. GUIDها در لاگ نمایش داده می‌شوند.
6. آنها را در `config.json` جایگزین کن.

## تست «من هنوز زنده‌ام»

بعد از تنظیم `RUBIKA_BOT_TOKEN` و `owner_guid`:

`Actions → Rubika Mod Bot → Run workflow`

اجرای دستی باید:
1. `getMe` را تست کند.
2. پیام **🟢 من هنوز زنده‌ام.** را به `owner_guid` بفرستد.
3. `getUpdates` را اجرا کند.
4. state را ذخیره کند.

اگر پیام زنده‌بودن رسید، یعنی اتصال GitHub Actions → Rubika API → ربات → پیوی مالک برقرار است.

## نکته درباره انتشار فایل

ربات از `file_id` فایل‌های موجود در روبیکا استفاده می‌کند و فایل‌ها را دوباره از کانال دانلود و آپلود نمی‌کند. بنابراین برای انتشار یک عکس/فایل/ویدیو که در آپدیت کانال منبع دارای `file_id` است، `sendFile` کافی است.

## ترتیب مود

این پروژه فرض می‌کند:
- پیام عکس مود می‌آید.
- سپس پیام فایل مود می‌آید.

اطلاعات کپشن عکس از قبیل عنوان، هشتگ، توضیحات و ورژن روی مود ذخیره می‌شود.

## زمان‌بندی

مقادیر فعلی:
- شروع: 11 تهران
- پایان: 23 تهران
- هر 4 ساعت یک ویدیو

سایر ساعت‌ها مود منتشر می‌شوند، مشروط به اینکه مورد ذخیره‌شده برای انتشار وجود داشته باشد.
